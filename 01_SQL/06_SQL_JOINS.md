# SQL Notebook – SQL JOINs

## Why JOINs Exist

SQL tables are intentionally separated to reduce redundancy and improve data integrity. JOINs allow us to combine related information from multiple tables into a single result set.

---

## Mental Model

A JOIN answers the question:

> "How do these two tables relate to each other?"

Instead of copying data into one large table, we connect rows using common keys.

---

## Types of JOINs

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- CROSS JOIN
- SELF JOIN
