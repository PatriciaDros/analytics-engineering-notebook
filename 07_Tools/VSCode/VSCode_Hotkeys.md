# VS Code Keyboard Shortcuts Cheat Sheet

A collection of the most useful keyboard shortcuts for everyday development.

> **Platform:** macOS
>
> _(Windows/Linux equivalents are shown where different.)_

---

# ⭐ Most Used Shortcuts

These are the shortcuts I use every day. If you're new to VS Code, learn these first.

| Shortcut         | Action                       | Why It's Useful                                  |
| ---------------- | ---------------------------- | ------------------------------------------------ |
| `⌘ Shift P`      | Command Palette              | Access almost every command in VS Code.          |
| `⌘ P`            | Quick Open File              | Open any file by typing part of its name.        |
| `⌘ K V`          | Markdown Preview to the Side | Live preview while writing documentation.        |
| `` Ctrl ` ``     | Toggle Integrated Terminal   | Open or hide the terminal instantly.             |
| `⌘ Shift F`      | Search Entire Project        | Search across every file in your workspace.      |
| `⌘ /`            | Comment/Uncomment Line       | Quickly comment out code.                        |
| `Shift Option F` | Format Document              | Automatically format code or Markdown.           |
| `⌘ D`            | Select Next Match            | Edit multiple matching words at the same time.   |
| `⌘ B`            | Toggle Sidebar               | Show or hide the Explorer to maximize workspace. |
| `⌘ \`            | Split Editor                 | View two files side-by-side.                     |

> **If I could only remember five shortcuts, they would be:**
>
> 1. `⌘ Shift P` — Command Palette
> 2. `⌘ P` — Quick Open File
> 3. `` Ctrl ` `` — Toggle Terminal
> 4. `⌘ K V` — Markdown Preview to the Side
> 5. `⌘ Shift F` — Search the Entire Project

# Command Palette

The most powerful shortcut in VS Code.

| Action          | macOS       | Windows/Linux  |
| --------------- | ----------- | -------------- |
| Command Palette | `⌘ Shift P` | `Ctrl Shift P` |

You can do almost anything from here:

- Open settings
- Change themes
- Install extensions
- Run Git commands
- Change Python interpreter
- Run Markdown preview
- etc.
