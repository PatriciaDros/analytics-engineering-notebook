# Analytics Engineering Notebook

## Purpose

This repository is my personal knowledge base as I transition into Analytics Engineering.

Rather than relying on scattered notes or chat history, this notebook captures the concepts, mental models, SQL patterns, data modeling principles, and design decisions that I want to remember and reuse.

## Guiding Principle

> Learn the thinking, not just the syntax.

My goal is not simply to write SQL.

My goal is to think like an Analytics Engineer.

## Organization

### 01_SQL

SQL concepts, query design, execution order, joins, CTEs, window functions, and reusable SQL patterns.

### 02_Data_Modeling

Dimensional modeling, fact tables, dimensions, star schemas, keys, and warehouse design.

### 03_Project_Renaissance

Architecture notes, design decisions, lessons learned, and documentation supporting Project Renaissance.

### 04_Business

Business concepts, KPIs, finance, metrics, and operational thinking that drive analytical solutions.

### 05_Career

Interview preparation, portfolio planning, resume notes, and career development.

### 06_Reference

Quick-reference material, cheat sheets, Git commands, SQL patterns, and reusable resources.
